# Work-Out Tracker - FitTrack Hub (Team VERTEX)
A full-stack web app to log workouts, follow plans, and track fitness progress.

## Live Demo
https://workout.freebuff.app/

## Features
- Sign in / authentication
- Dashboard with health metrics and charts
- Live workout session player with timer
- Workout logging
- Workout plans
- Progress charts
- Goals
- Exercise library

## Tech Stack
- React 19
- TypeScript
- Vite
- React Router v7
- Convex (backend and database)
- Bun (package manager)

## How to Run
1. Clone this repository
2. Run `bun install` (or `npm install`)
3. Copy `.env.example` to `.env.local` and fill in the values
4. Run `bun run dev` (or `npm run dev`)
5. Open the local URL shown in the terminal
